# Trabajo-Final-Curso-de-Data-Science-UTN-BA
Trabajo final del curso de Data Science de la UTN BA realizado con datos abiertos de la secretaría de educación

Se realizó analisis de datos, limpieza de la base de datos, selección de características y se aplicó un método de clusterización para observar el comportamiento de los grupos.

En el repositorio encontrarán un enlace al notebook de google colab y el archivo de base de datos utilizado en formato de csv.
